Connect the extension to your Readlater server.

The address you open Readlater at. http:// is only allowed for localhost / 127.0.0.1.

Create an API key

Use Create an API key (opens Readlater’s Settings), create a key and paste it here. Leave both fields empty and save to disconnect.
